课本的课后文章只有那么几段，想多读点就得自己找。这五篇短文是照 1–24 课的语法和词汇范围写出来的，用到的句型基本都能在笔记里找到出处，没往里塞受身、使役、条件形（ば／たら）、ておく、てしまう、ので这些还没学的东西。

读法建议：先不看翻译，一口气把日语读完，遇到卡住的地方画个圈，读完再看翻译和语法点。生词不用每个都查，能顺着句子猜出意思的先放过。

# 一、わたしの一日（我的一天）

> わたしは李です。中国から来ました。今は東京のアパートに住んでいます。
>
> 毎朝六時半ごろ起きます。七時に朝ご飯を食べて、七時半に家を出ます。駅まで歩いて十分ぐらいかかります。電車で会社へ行きます。電車の中では、いつも本を読みます。
>
> 仕事は九時に始まって、五時に終わります。昼休みは十二時から一時までです。いつも社員食堂で食べます。食堂の料理はあまり高くないです。
>
> 夜は七時ごろうちへ帰ります。うちへ帰ってから、日本語を一時間勉強します。十一時ごろ寝ます。

## 中文翻译

我是小李，从中国来的，现在住在东京的公寓里。

每天早上六点半左右起床。七点吃早饭，七点半出门。走到车站大约要十分钟，然后坐电车去公司。在电车里，我总是看书。

工作九点开始，五点结束。午休从十二点到一点，我一般在员工食堂吃。食堂的饭菜不太贵。

晚上七点左右回家。回到家以后学一小时日语，十一点左右睡觉。

## 语法与词汇

| 句子 | 语法点 | 课次 |
| :--- | :--- | :--- |
| アパート**に住んで**います | `～ています` 表动作结束后留下的结果状态，不是"正在住" | 16 |
| 駅**まで**歩い**て**十分ぐらい**かかります** | `まで` 表终点；`かかります` 问花费的时间／钱 | 6、13 |
| ご飯を食べ**て**、家**を出**ます | `て形` 连接两个相继发生的动作；`家を出る` 的 `を` 表离开的场所 | 14 |
| 電車の中**では** | `で` + `は`，把场所提出来做话题（带一点对比） | 6 |
| 昼休みは十二時**から**一時**まで**です | `から～まで` 还能接在`です`前面，表示一个时间段 | 5 |
| 日本語を一時間勉強します | 表示**持续时长**的时间词后面不加 `に` | 13 |
| あまり高くないです | `あまり` + 否定，程度不高 | 9 |

两个容易写错的地方：

- `毎朝`、`今`、`昨日` 这类词后面不能加 `に`，但 `六時半に` 这种带数字的要加。
- `一時間`（持续多久）不加 `に`，`七時に`（在哪个时间点）要加 `に`。同一个"时间"，助词不一样。

# 二、週末（周末）

> わたしの週末は、毎週同じではありません。
>
> 土曜日は、友達に会ったり、映画を見に行ったりします。先週の土曜日は、新宿で日本の映画を見ました。言葉はあまり分かりませんでしたが、とてもおもしろかったです。日本の映画を見たことがありますか。わたしは何度か見たことがあります。
>
> 日曜日は、いつも家でゆっくり休みます。天気がいい日は、近くの公園を散歩します。公園は静かで、人があまりいません。
>
> 来週の日曜日は、友達と一緒に山へ行きます。山は駅から遠くないです。バスで一時間ぐらいかかります。李さんも一緒に行きませんか。

## 中文翻译

我的周末不会每周都一样。

周六有时和朋友见面，有时去看电影。上周六在新宿看了部日本电影。台词不太听得懂，不过非常有意思。你看过日本电影吗？我看过好几次。

周日总是在家好好休息。天气好的日子，就在附近的公园散散步。公园很安静，人也不多。

下周日要和朋友一起上山。山离车站不远，坐公交大概一小时。小李也一起去吗？

## 语法与词汇

| 句子 | 语法点 | 课次 |
| :--- | :--- | :--- |
| 友達に会っ**たり**、映画を見に行っ**たり**します | `たり～たりします` 列举若干有代表性的动作 | 23 |
| 見**たことが**あります | 曾经有过某种经历；`何度か` 是"好几次" | 21、21 |
| 分かりませんでした**が**、おもしろかったです | `が` 表转折 | 16 |
| 公園**を**散歩します | 自动词表移动时，`を` 是经过的场所，不是宾语 | 14 |
| 公園は静か**で**、人があまりいません | 二类形用 `で` 并列 | 16 |
| 行き**ませんか** | 提议、邀请；语气比 `ましょう` 委婉 | 17 |

注意这几个词的区别：

- `見たことがあります`（有过经历）≠ 单纯的过去式 `見ました`（那次看了）。前者说的是"活到现在有没有过"，至少半年前的事，课文里说过近期的经历不能用这个句型。
- `行きませんか` 是邀请；`行きますか` 只是问事实。翻译成中文都是"去吗"，日语里不是一回事。

# 三、新しい部屋（新房间）

> わたしは先月、新しいアパートへ引っ越しました。前のアパートは駅から遠くて、不便でした。新しい部屋は、前の部屋ほど広くありませんが、駅に近くて明るいです。
>
> 引っ越しの日、友達の小野さんが手伝いに来ました。小野さんはわたしの荷物を一緒に運んで、それから、古いテーブルをくれました。「このテーブルは、わたしの父が作ったんですよ。」と小野さんは言いました。わたしは小野さんに、中国のお茶をあげました。
>
> 新しい部屋には、まだテレビがありません。だから、夜はラジオを聞いたり、本を読んだりします。来月、電気屋へテレビを買いに行きます。わたしは小さいのがいいと思います。小野さんは「大きいテレビを買ったほうがいいよ。」と言いましたが、わたしの部屋は狭いですから、大きいのは置くことができません。

## 中文翻译

上个月我搬进了新公寓。原来的公寓离车站远，很不方便。新房间没有原来的房间那么宽敞，不过离车站近，也亮堂。

搬家那天，朋友小野来帮忙。小野帮我一起搬行李，然后送了我一张旧桌子。"这张桌子是我父亲做的哦"，小野说。我送了中国的茶叶给小野。

新房间里还没有电视。所以晚上就听听广播、看看书。下个月要去电器店买电视。我觉得小一点的就行。小野说"还是买个大电视好"，可我的房间小，大的放不下。

## 语法与词汇

| 句子 | 语法点 | 课次 |
| :--- | :--- | :--- |
| 前の部屋**ほど**広くありません | `ほど` + 否定，表示"不及"，句尾必须否定 | 12 |
| 駅から遠く**て**、不便でした | 一类形 `くて` 并列，时态由句尾控制 | 16 |
| 手伝い**に**来ました | `动词ます去ます + に` 表移动的目的 | 13 |
| 古いテーブルを**くれました** | `くれる` 站在接受者（我／己方）一方叙述 | 8 |
| 作った**んです**よ | `んです` 说明情况、解释缘由 | 24 |
| と小野さん**は言いました** | `と` 引用；前面小句要用简体形 | 24 |
| 買っ**たほうがいい**よ | `た形 + ほうがいい` 建议对方这么做 | 21 |
| 置く**ことができません** | `动词基本形 + ことができます` 表能力、可能 | 20 |

这一篇里 `あげる` 和 `くれる` 同时出现了，正好对照：

- `小野さんがテーブルをくれました` —— 物品朝我这边来，用 `くれる`。
- `わたしは小野さんにお茶をあげました` —— 物品从我这边出去，用 `あげる`。

如果把第二句说成 `小野さんはわたしにお茶をあげました` 就错了，方向反了。

# 四、病気（生病）

> 昨日、わたしは会社を休みました。朝から頭が痛かったんです。
>
> 午前中、病院へ行きました。医者は「風邪ですね。今日は仕事をしないで、ゆっくり休んでください。」と言いました。それから、「夜はお風呂に入ってはいけませんよ。」と言いました。
>
> わたしは「明日、会社へ行ってもいいですか。」と聞きました。医者は「熱がありませんから、行ってもいいですが、無理をしないほうがいいですよ。」と言いました。
>
> うちへ帰ってから、薬を飲んで、夜まで寝ていました。夜、小野さんに電話をもらいました。「大丈夫ですか。何か食べましたか。」「いいえ、まだ何も食べていません。」「それはいけませんね。食べたくないですね。でも、食べなくてもいいですよ。水はたくさん飲まなければなりませんよ。」
>
> 「はい、分かりました。明日は大丈夫だと思います。ありがとうございます。」

## 中文翻译

昨天我向公司请了假。从早上起头就疼。

上午去了医院。医生说："是感冒啊。今天别工作了，好好休息。"然后又说："今天晚上不要泡澡。"

我问："明天可以去公司吗？"医生说："没发烧，去也可以，不过最好别勉强。"

回家以后吃了药，一直睡到晚上。晚上小野打来了电话。"没事吧？吃东西了吗？""没有，还什么都没吃。""那可不行啊。不想吃的话不吃也可以，但水一定要多喝。"

"好的，我知道了。明天应该没事了，谢谢。"

## 语法与词汇

| 句子 | 语法点 | 课次 |
| :--- | :--- | :--- |
| 頭が痛かった**んです** | `んです` 解释原因，比直接说 `痛いです` 更像在说明缘由 | 24 |
| 仕事をし**ないで**、休んでください | `ない形 + で + ください`，`てください` 的否定 | 19 |
| お風呂に入っ**ては**いけません | `ては いけません` 表禁止 | 15 |
| 行っ**ても**いいですか | `ても いいです` 表许可，疑问形式即请求许可 | 15 |
| 無理をし**ないほうがいい**ですよ | `ない形 + ほうがいい`，建议别这么做 | 21 |
| まだ何も食べ**ていません** | `まだ` + 否定，表示"还没" | 16 |
| 食べ**なくても**いいです | 不做某事也可以 | 19 |
| 飲ま**なければなりません** | 必须做；字面是"不喝的话不行"，否定之否定 | 19 |

一个细节：医生说 `熱がありませんから、行ってもいいですが` 用的是 `が` 的转折，`行ってもいい` 后面接 `が`，把"可以"和"最好别勉强"两层意思连起来。这是 16 课的转折 `が`，跟 24 课那种"铺垫"的 `が` 不同——这里是真的在转折。

# 五、京都と奈良（京都和奈良）

> 去年の夏、わたしは京都へ行きました。京都へ行ったことがありますか。
>
> 京都は、お寺や神社がたくさんあります。一日中歩きましたから、とても疲れました。でも、紅葉がとてもきれいでした。京都の紅葉は、日本で一番きれいだと思います。
>
> 次の日、奈良へ行きました。奈良もお寺が多いですが、京都ほどにぎやかではありません。雨でしたから、観光客が少なくて、ゆっくり見ることができました。東大寺の大仏は、本当に大きかったです。
>
> 京都と奈良と、どちらが好きですか。わたしはどちらも好きです。でも、わたしは奈良のほうが好きです。奈良は静かで、人が少ないですから。

## 中文翻译

去年夏天我去了京都。你去过京都吗？

京都有很多寺庙和神社。走了一整天，累得不行。不过红叶非常漂亮。我觉得京都的红叶是日本最美的。

第二天去了奈良。奈良的寺庙也很多，但没有京都那么热闹。因为下雨，游客很少，可以慢慢地看。东大寺的大佛真的很大。

京都和奈良，你喜欢哪个？我两个都喜欢。不过我更喜欢奈良，因为奈良安静，人也少。

## 语法与词汇

| 句子 | 语法点 | 课次 |
| :--- | :--- | :--- |
| 京都へ行っ**たことが**ありますか | 问有没有过某种经历 | 21 |
| お寺**や**神社がたくさんあります | `や` 列举其中重要的几项，暗示还有别的 | 11 |
| 一日中歩きました**から** | `から` 表原因，放在原因小句末尾 | 11 |
| 日本**で**一番きれいだ**と思います** | 场所 + `で` + 一番；`と思います` 缓和语气 | 12、24 |
| 京都**ほど**にぎやかではありません | `ほど` + 否定 | 12 |
| 少な**くて**、ゆっくり見ることができました | 一类形て形并列；`ことができました` 是过去式 | 16、20 |
| どちら**も**好きです | `どちらも` 表示"两个都" | 12 |

`と` 和 `や` 的区别在这里体现得最清楚：

- `お寺と神社` —— 只有这两样，全部列举完了。
- `お寺や神社` —— 寺庙、神社这类东西，还有别的没说。

# 练习

把下面六句译成日语，练的都是前面短文里出现过的句型。

1. 我每天早上七点左右起床，坐电车去公司。
2. 你看过歌舞伎吗？—— 没有，一次都没看过。
3. 因为今天很冷，最好别出去了。
4. 我想明年去日本。不过能不能去还不知道。
5. 这个公园又安静又宽敞，人也不太多。
6. 医生说了"在这里不能抽烟"。

## 参考答案

1. 毎朝七時ごろ起きて、電車で会社へ行きます。
   　　（`て形` 连接两个动作；`ごろ` 后面不加 `に`）
2. 歌舞伎を見たことがありますか。ーいいえ、一度もありません。
   　　（否定回答不能说 `ことがありません`，用 `一度もありません` 或 `ありません`）
3. 今日は寒いですから、出かけないほうがいいです。
   　　（`ない形 + ほうがいい`；原因用 `から`）
4. 来年日本へ行きたいです。でも、行くかどうか分かりません。
   　　（是非问句塞进句子里用 `か どうか`，不是 `行くか`）
5. この公園は静かで広くて、人があまりいません。
   　　（二类形 `で` + 一类形 `くて` 可以混着并列）
6. 医者は「ここでタバコを吸ってはいけません。」と言いました。
   　　（`と` 引用，`言いました` 用过去式）

# 到最后

这五篇加起来大概覆盖了 1–24 课的主要句型：日常作息（时间助词、`てから`）、周末娱乐（`たり`、`たことがある`）、搬家（授受动词、`んです`、`ほど`）、生病（`ない形`、`てもいい`、`なければなりません`）、旅行（比较、`一番`、`と思います`）。

下一步可以试着自己改写：把上面任意一篇的主角换成你自己，把时间、地点、动词换掉，但句子骨架不动。能做到这一步，说明句型是真会了，而不是背下来了。实在卡住的地方，翻回对应的课文和笔记，比硬猜有用。
