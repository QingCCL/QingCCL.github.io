首先，从动词的基本形（简体）开始，如`書く（写）`。动词有“活用”这个概念，指动词本身进行变化（或不变化），然后接不同语法成分。

|  活用  |  词语变化  | 例如                                                         |
| :----: | :--------: | :----------------------------------------------------------- |
| 未然形 | 書か／書こ | 用于连接某些后续成分，例如「書かない」（不写）、「書こう」（打算写、写吧）。 |
| 连用形 |    書き    | 常用于连接后续成分，例如「書きます」（写）、「書きたい」（想写）。 |
| 终止形 |    書く    | 用来结束句子、陈述一件事。例如「本を書く。」（写书。）       |
| 连体形 |    書く    | 用来修饰名词。例如「本を書く人」（写书的人）。               |
| 假定形 |    書け    | 常用于表示条件，后接「ば」，形成「書けば」（如果写）。       |
| 命令形 |    書け    | 表示命令，例如「早く書け！」（快写！）。                     |

终止形和连体形有时长得完全一样，假定形和命令形也可能长得一样。这时需要根据上下文来判断。

书上所说的 `て形`、`た形`、`たい形` 等等，这些是通过动词活用形成的具体变化。

比如 `書きたい` 可以说是書く的 `たい形` 也可以说是書く的连用形加たい。这两者不冲突。

而　`ます`　形并不是独立于动词基本型存在，而是由动词基本形，通过活用的　`连用形`　变为　`書き`　后，续接　`ます`　变成　`書きます`这种礼貌表达形式。

动词基本形的时态变化ます形也全都有，所以常把 `ます形` 与 `基本形` 对立来看。但实际ます形是基本型的一种活用变化。



|      时态      | 基本形       | ます形           |
| :------------: | :----------- | :--------------- |
| 现在/将来 肯定 | 書く         | 書きます         |
| 现在/将来 否定 | 書かない     | 書きません       |
|   过去 肯定    | 書いた       | 書きました       |
|   过去 否定    | 書かなかった | 書きませんでした |

另外，ます形也可以继续“活用”，指ます进行活用变化

| 「ます」的活用形 | 形式         | 例子                     |
| ---------------- | ------------ | ------------------------ |
| 未然形           | ませ／ましょ | 書きません、書きましょう |
| 连用形           | まし         | 書きました、書きまして   |
| 终止形           | ます         | 書きます                 |
| 连体形           | ます         | 書きますとき（较少见）   |
| 假定形           | ますれ       | ますれば（较少见）       |





# 动词

## 一类动词（五段动词）

1. **结尾是`う`段非`る`的动词，肯定是5段动词**

   - 書く　かく　 
    - 探す　さがす
   - 勝つ　かつ
   - 遊ぶ　あそぶ
   - 読む　よむ

2. **あ、う、お段+る**

   看结尾る前面的词是否为あ、う、お段。

   - 困る　こまる
   - 怒る　おこる
   - やる

3. **特例**

   - 切る　きる　切
   - 帰る　かえる　回家
   - 走る　はしる　跑

## 二类动词（上一段动词、下一段动词）

い段＋る和え段＋る结尾的单词

おきる

たべる

みえる

おしえる

うける

## 三类动词（カ变、サ变）

くる

する

# ます

## 1类动词

う段要变成同行的い段＋ます

書く　かく　ー＞　書きます

吸う　すう　ー＞　吸います

切る　きる　ー＞　切ります

呼ぶ　よぶ　ー＞　呼びます　

## 2类动词

る变ます

教える　おしえる　ー＞　教えます

開ける　あける　ー＞　開けます

調べる　しらべる　ー＞　調べます

得る　える　ー＞　得ます

## 3类动词

死记硬背

来る　ー＞　来ます　　くる　ー＞　きます

する　ー＞　します

# たい

原型变`ます`形然后去掉`ます`

「たい」接上动词后，整个表达像い形容词一样活用：

| 表达             | 中文       |
| ---------------- | ---------- |
| 食べたい         | 想吃       |
| 食べたくない     | 不想吃     |
| 食べたかった     | 以前想吃   |
| 食べたくなかった | 以前不想吃 |

# 形容词

## 一类形容词

1. い结尾
2. 汉字+い　熱【あつ】い、冷【つめ】たい、寒【さむ】い、暖【あたた】かい

## 二类形容词

1. 不以い结尾
2. 特例

綺麗　きれい、詳細　しょうさい、静か、便利、愉快　ゆかい、嫌い　きらい　这几个单词以い结尾，但汉字是没有い的，读音最后是い，这些属于二类形

## 变形

| 类型 | 例词 |    肯定    |                否定                |    过去肯定    |                   过去否定                   |
| :--: | :--: | :--------: | :--------------------------------: | :------------: | :------------------------------------------: |
| 一类 | 熱い | 熱い`です` | 熱`くないです` ／ 熱`くありません` | 熱`かったです` | 熱`くなかったです` ／ 熱`くありませんでした` |
| 二类 | 好き | 好き`です` |    好き`[では／じゃ]ありません`    |  好き`でした`  |       好き`[では／じゃ]ありませんでした`       |



# て／た形

た形就是て形的 て换成た、で换成だ。

## 一类动词

|    原形    | て／た形 |
| :--------: | :------: |
|     す     |   して   |
|     く     |   いて   |
|     ぐ     |   いで   |
| う／つ／る |   って   |
| ぶ／む／ぬ |   んで   |

話す　話して

磨く　磨いて

急ぐ	急いで

洗う　洗って

待つ　待って

やる　やって

遊ぶ　遊んで

読む　読んで

死ぬ　死んで

行く　行って　特例



## 二类动词

| 原形 | て／た形 |
| :--: | :------: |
|  る  |    て    |

食べる　食べて

調べる　調べて

## 三类动词

| 原形 | て／た形 |
| :--: | :------: |
| する |   して   |
| 来る |   来て   |

# ない形

未然形+ない

## 一类动词

词尾从`う段`变成`あ段`＋ない。注意：う→わ

## 二类动词

去掉词尾`る`＋ない

## 三类动词

する→しない

来る→こない

特殊：ある
ある的ない形不是あらない，而是ない。
